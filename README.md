# K-Means Clustering from Scratch
Consolidate your knowledge of K-Means by creating a working algorithm from scratch. Find appropriate positions for  
clusters on the training loop, select an appropriate **k** to see how well the whole thing performs.

In this project, you'll dive into implementing one of the simplest algorithms to cluster your data: K-Means.  
Explore it from scratch using only numpy and matplotlib for visualization. We'll stick to the Wine dataset.

## Stages

### Stage 1/6: Where do you belong

Search for the nearest cluster center for each object.

### Stage 2/6: Calculating the means

Find a new cluster center using the information from the previous step.

### Stage 3/6: Get it wrapped

Implement the whole fit-predict class and make the algorithm work.

### Stage 4/6: Find that K

Try using your coded algorithm with different values of k to find an appropriate one.

### Stage 5/6: Automation is the Key

Automate the process of finding an appropriate k by writing a function for that.

### Stage 6/6: The final stage

Finish the task by using the power of your code to predict clusters for each object of the dataset and compare them  
to the "real" clusters (classes).
